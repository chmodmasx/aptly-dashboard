# Third-party references

This prototype was designed from the public architecture and visual conventions of:

- `agmmnn/tauri-ui` — MIT, according to its README/package metadata.
- shadcn/ui — used as the UI design system reference and compatible component structure.
- Tauri — desktop application runtime.

No vendored copy of the `tauri-ui` repository is included. The application-specific source in this archive was written for the SupraLINUX Aptly dashboard prototype.
